FAQ

Questions, answered

Is My Stave free?

Yes. You can download it from this page at no cost.

Does it need internet?

No. The vault works offline. The app only checks for a new version when it opens, and sends nothing from your vault.

What happens if I forget my PIN?

Use "Forget your PIN?" on the lock screen and enter your backup code to set a new PIN.

How do I move to a new phone?

Use "Share a copy of the backup" in the app and save the file somewhere safe. On the new phone, install My Stave, tap "Restore from backup", pick the file and enter your backup code.

Is it available on iPhone?

Not right now. My Stave is for Android.
